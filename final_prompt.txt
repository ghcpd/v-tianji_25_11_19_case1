Prompt:

You are a senior JavaScript engineer reviewing a complex pure JavaScript file that contains multiple hidden functional bugs. The file does not use React, Vue, or any other third-party library.

Your tasks:

Detect every functional bug related to:

State and variable management

Async behavior and timing issues

Control flow logic

Race conditions or stale state

Incorrect function outputs

For each bug, provide:

A clear explanation

The root cause

A minimal safe fix

A unified diff-style patch

After fixing all issues, output the corrected JavaScript code as a single runnable file.

Generate automated tests using Jest (or plain Node.js test framework) to verify:

All fixed bugs do not regress

Async functions behave correctly

State and variable changes are correct

Control flow and timing issues are covered

Generate the test file(s) for this run (file name can be arbitrary). Ensure that the tests are executed and pass successfully before finalizing the fix.

Evaluation procedure:

Run the model 5 separate times on the same JS file

Ensure that each fix passes its tests before proceeding

Record the output code, test results, and bug lists for each run

After all 5 runs, provide a summary including:

Total bugs detected in each run

Bugs that were inconsistently detected or missed

Differences in fix approaches across runs

Any inconsistencies in the final code or test coverage

Overall assessment of Flaky behavior
