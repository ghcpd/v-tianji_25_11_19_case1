## 🔍 Bugs found, root cause & fix

1) Bug: unsubscribe removed wrong listener (splice idx - 1)
- Explanation: subscribe() returned an unsubscribe that removed the wrong index (idx - 1). When idx = 0, splice(-1, 1) removes last listener, causing wrong removals and memory leaks.
- Root cause: off-by-one error.
- Fix: splice(idx, 1).

2) Bug: notify passed live GlobalState reference to listeners and could be mutated by listeners.
- Explanation: A listener could mutate GlobalState causing inconsistent render state or race conditions.
- Root cause: mutating global reference passed directly.
- Fix: notify now passes a shallow snapshot (copy) to listeners and catches listener errors.

3) Bug: refresh/ loadItems produced duplicates and used a confusing double-await pattern.
- Explanation: refresh created a promise, awaited it twice; sorting was applied on the awaited value but not done safely; items were simply pushed and duplicates could accumulate.
- Root cause: race/duplication logic and misuse of awaiting same Promise twice; merge without dedup.
- Fix: fetch once, sort new items when needed, merge only non-duplicate IDs.

4) Bug: search used random timeout and no promise, making it hard to await in tests or code.
- Explanation: callers had no way to await search completion, leading to race conditions in tests and consumers.
- Fix: search returns a Promise that resolves when the filter is set and notify is done.

5) Bug: runSimulation executed immediately on import.
- Explanation: tests import the module, which started the simulation (setInterval, console.clear, render), making testing noisy and unpredictable.
- Fix: only run Simulation when the file is executed directly; otherwise provide exports for tests.
